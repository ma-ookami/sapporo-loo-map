# 札幌トイレマップ(Web 版)

すすきの周辺のトイレを地図で探す PWA(スマホ向けのアプリ風画面)。ヒグマのマスコット「くまトイ」。ビルドなし・GitHub Pages 向け。
iOS ネイティブ版(Expo)は `../sapporo-loo-map`。データとマスコットは共通。

## 画面
- 下のタブバー(地図・＋追加・リスト)と、下から出るシート(最寄りボタン・リスト・詳細)。シートはつまみのタップ/上下スワイプで開閉
- 上のチップで絞り込み(無料・車いす・24時間)。最寄りボタンもリストも絞り込み後の結果
- 詳細: 階・無料/有料・車いす・メモ、「きれい/混んでた/使えなかった」を1タップで報告(24時間だけ集計表示)、ルート(Google マップ徒歩)
- コンビニ: OSM の既存 131 件を最初から表示(貸し出しは「未確認」の薄いピン。引いた地図では隠す)。詳細で 借りられる/声かけ/× を1タップで報告 → 多数決(同数は声かけ)で色が決まり、〇・声かけだけが最寄り/リストに出る。追加画面で「コンビニ」を選ぶと、ブランド(セブン・ファミマ・ローソン・セイコーマート・その他)と貸し出し(〇 / 店員に声をかけて / ×)を選択式で登録。ピンは🏪で縁の色が貸し出し可否(緑・橙・灰)。×は最寄りボタンとリストから外す
- ＋追加: 現在地に📍が置かれた状態で始まり、動かして「ここにする」→ 名前・階(B1〜10F〜)・料金・車いす・メモ → 登録。追加は本人だけ削除可

- 追加時の星評価(使いやすさ・場所のわかりやすさ 1〜5。同じ星をもう一度で取り消し)。詳細に星で表示
- 配慮の案内: 初回に「使う前に」(お客さん専用のトイレもある / できるだけ買い物を・混雑時は遠慮 / 情報は投稿)を1回表示。右上の ⓘ でいつでも。詳細にも短い注意書き

- ダークモード: 設定で 自動/ライト/ダーク を選べる(自動は端末に合わせる。地図は OpenFreeMap `dark`、画面は CSS 変数)
- 「いま空いてる」チップ: `js/hours.js` が OSM の opening_hours(曜日・時間帯・日またぎ・off)を読んで日本時間で判定。**営業時間が分からないものは出す**(営業時間外と分かるものだけ隠す)。営業中/営業時間外のタグも表示
- 現在地が遠い(1.5km 超)ときは「すすきのへ」ボタンで地図を移動

- 名前のないトイレは「トイレ(○○ 付近)」と表示(近くの施設・通りの名前。`../sapporo-loo-map/tools/fetch-areas.js` が OSM から取り `areas.json` に書き、`build-data.js` が取り込む。木・駅の出口・長い名前は除外)
- プライバシー・データ出典は `privacy.html`(「使う前に」の下から開く)。App Store に出すときのポリシーにも流用する
- キャッシュ対策: `node tools/stamp.js` が index.html の `?v=` を各ファイルのハッシュにそろえる。`.git/hooks/pre-commit` で自動実行(別の PC では、`.git/hooks/pre-commit` に `node tools/stamp.js && git add index.html` を置く)

- 絞り込みボタン(無料・車いす・いま空いてる・24時間・借りられるコンビニ)は、設定の「画面に出す絞り込みボタン」でオン/オフ。**無料・車いす・24時間は初期はオフ(出さない)**、いま空いてる・借りられるコンビニは初期オン。オフにしたボタンの絞り込みは解除される(`js/settings.js` の `applyChips`)
- **地図スタイルの入れ替えは `reloadStyle()`(`setStyle(..., {diff:false})`)を使う。** 差分更新だと `style.load` が来ず、`tidyStyle` が動かないため、日英併記・店アイコン・道路標識が戻る(`node tools/test-style-switch.js` で確認)
- 地図の色: シンプル(淡い。positron / 暗いときは dark)とカラー(bright / 暗いときは fiord)。右上の重なった四角のボタン、または設定の「地図の色」で切り替え。初期はシンプル(`js/map.js` の `mapStyle` / `reloadStyle`)
- 現在地: 青い点(広がる輪つき)。右上の◎で移動。許可がないときは、ボタンを押すと理由(iPhone の設定の場所)をトーストで出す。設定にも「現在地」の状態と「さがす」。最初に取れたとき、地図を動かしておらずすすきの近く(3km 以内)なら、そこへ寄る(`js/map.js` の onPos / locateNow)
- 地図の文字は1言語だけ(設定の「地図の文字」: 日本語 = name:ja → name / English = name_en → name:latin → name)。スタイルの元は日英併記なので、`style.load` の時点で `tidyStyle` が書き換える(読み込み中に併記が見えないように)
- 設定(右上の歯車のアイコン): テーマ(自動/ライト/ダーク。`html[data-theme]`)・地図の文字(日本語/English)・歩く速さ(60/80/100 m/分)・振動・最寄りにコンビニも出す・借りられるか不明のコンビニを地図に出す・自分が追加したもの/自分の報告(一覧と削除・取り消し)・使う前に/プライバシー/連絡/版/この端末の記録を消す。保存は localStorage `loo-settings`(`js/settings.js`)

## 構成
- 地図: MapLibre GL 4.7.1 + OpenFreeMap `positron`(淡い地図。キー不要。ラベルの整え方は sakabazu と同じ)
- デザイン: ミニマル・フロスト(すりガラス・アクセント1色 #c4521f・細線アイコン `js/icons.js`)。色の意味は 橙=トイレ / 緑=借りられる・無料 / 橙黄=声かけ / 黒=選択中
- マスコット `js/bear.js`(丸い体・頭の寝ぐせ風の毛(向きと長さがばらばらな3本)・クリーム色のお腹・4表情・ゆれ/まばたき)。アイコン生成は `node tools/make-icons.js`
- `js/settings.js` 設定 / `js/geo.js` 距離 / `icons.js` アイコン / `icons.js` アイコン / `bear.js` マスコット SVG / `cloud.js` 保存 / `map.js` 地図・ピン・現在地 / `ui.js` シート・タブ・チップ / `add.js` 追加 / `main.js` 起動
- データ: `data/toilets.js`(`node tools/to-js.js` で `../sapporo-loo-map/data/toilets.json` から生成)。`index.html` は直接開いて確認できる
- 確認: `node tools/test-hours.js`(営業時間の判定)/ `test-dark.js` / `test-add.js` / `node tools/test-conv.js`(ローカルモードで 絞り込み・リスト・追加・詳細・報告・削除 を通す。playwright-core は taskline のを借用)

## 保存先(Firebase)
- 保存先は PaP と同じ **playground**(`playground-d8897`)の Firestore。コレクションは `loo-toilets`(追加されたトイレ)と `loo-reports`(一言報告)。他のアプリと名前が重ならないよう `loo-` を付けている
- `firebase-config.js` は playground の設定を入れてある。`?local=1` を付けて開くと、この端末だけに保存するローカルモード(テスト・試し書き用。テストは全部これで動く)
- Firestore につないだ状態は未確認(Java が無くエミュレータが使えない)
### ルールを足す手順(playground は他のアプリと共有)
1. Firebase コンソール → Firestore → ルール を開く
2. 現在のルールの `match /databases/{database}/documents { ... }` の中に、`firestore.playground-snippet.rules` の `match` 2つ(`loo-toilets` と `loo-reports`)を足して公開する
   - PaP のルールだけが入っている場合は、`firestore.playground.rules`(PaP + 札幌トイレマップ)をそのまま貼ってもよい。**他のアプリのルールもコンソールに入っているなら、これは使わずスニペットだけを足す**
3. Authentication で **匿名** が有効なこと(PaP が使っているので有効のはず)と、承認済みドメインに `ma-ookami.github.io` があること(PaP と同じドメインなら追加不要)を確認
- 荒らし対策は簡易(項目・文字数・札幌周辺の座標の制限、削除は本人のみ、報告は1人1トイレ1件)。連続投稿の制限は未実装。App Check は PaP と同じく未設定
